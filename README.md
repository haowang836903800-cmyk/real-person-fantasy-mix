# real-person-fantasy-mix

一个 Codex Skill：把旅行、街拍或生活照片制作成“真实摄影人物与场景 + 二维幻想元素”的混合画面。

它专门解决一个容易发生的风格漂移：幻想元素加入照片后，生成模型常会顺手把真人也画成插画。本 Skill 把真人摄影质感设为最高优先级，并通过空间关系设计、提示词约束和一次有限修正，让幻想层围绕真人与真实物体生长。

## 安装

将仓库目录复制或克隆到 Codex Skills 目录：

```bash
git clone https://github.com/haowang836903800-cmyk/real-person-fantasy-mix.git ~/.codex/skills/real-person-fantasy-mix
```

重新启动或刷新 Codex 后，可显式调用：

```text
用 $real-person-fantasy-mix 处理这张旅行照片，人物保持真人摄影质感。
```

## 输入建议

- 至少一张包含真人与真实场景的清晰照片。
- 可选一张风格参考；它只决定新增插画层，不替换人物身份与场景。
- 需要系列统一时，可把上一张成图作为风格参考，并明确不复制构图。

## 豆包适配

从 v1.1.0 起，Skill 内置独立的豆包运行时适配层。它只在宿主或图像工具明确标识为豆包 / Doubao，或用户明确要求用豆包出图时触发；Codex 和其他环境继续使用原有通用规则，不受影响。

适配层包含更紧凑的中文提示词编译方式、单一风格锚点、成熟编辑插画控制、两阶段合成与局部修正、最高原生质量策略，以及针对“低幼、课本插图、贴纸感、低清晰度”的专用质量门。

## 澄澈电影奇想

从 v1.2.0 起，Skill 为大天空、海面、山野和远景旅行照片增加可按场景启用的原创审美模块。它以真实天气、逐场景光色、日常地点锚点、负空间和尺度反差组织一个诗意主奇观，提高画面的电影感与情绪密度。

该模块不会要求模仿任何在世艺术家或复制具体影视作品，也不会把真人与整张实景照片转成动画。近距离室内、美食、商品或缺少环境纵深的画面不会机械套用。

## 严格真人锁定

从 v1.2.2 起，人物保真不再只要求“看起来像本人”，而是优先保留原照片中的人物像素。允许整张照片做克制的统一调色，但禁止对人物进行生成式重绘、美颜、磨皮、五官修复、发丝重建、身体重塑或虚构补光。工具支持时应通过保护遮罩与分层合成，让幻想层生成在人物之外，再将原图人物与原影子合成回来。

从 v1.3.0 起，豆包分支不再依赖一句“人物保持不变”来碰运气，而是先按工具能力选择独立幻想层、受保护区域局部生成或外部合成。豆包电影感也被拆成主光影事件、三层空气纵深、二维光色层次、场景取色和摄影融合等可执行规则，以减少人物漂移、纯色色块和廉价 TV 卡通感。

从 v1.4.0 起，豆包在第一次生成前必须完成一份场景专属视觉蓝图：摄影底片、故事动词、主奇观原型、场景材质来源、视觉路径、三层空间、三处融合关系与光色脚本。Skill 将已认可效果拆成四层二维光色、边缘软硬、密度地图和功能化情节元素等可测量语法，并提供海岸、城市、山林与咖啡馆四组异质推理样例，同时明确禁止照搬案例中的鲸鱼、花丛、纸飞机或固定组合，让不同照片保留同一种审美与绘制逻辑，而不是复制同一种题材。

从 v1.5.0 起，Skill 附带可执行的像素安全合成流程：macOS Vision 只生成人物保护遮罩，图像模型只生成透明幻想层，本地脚本按照“原照片 → 后景幻想 → 原照片人物像素 → 安全前景幻想”的顺序输出无损 PNG，并生成像素验证报告。保护区域只要有一个像素变化就拒绝交付；整图图生图、JPEG 和“人物可能有细微差异”不再允许作为完成结果。豆包分支还会先选择当前可用的最新正式静态生图模型与最高质量档，拒绝极速、草稿、漫剧和视频模式，并拦截网感海报脸、金色玻璃 CG、游戏光轨与批量素材图标等廉价漫剧画风。

从 v1.6.0 起，豆包默认改为“摄影底板 2.5D 空间增量”：完整原照片永不拆分，人物遮罩只作为禁止绘制安全区，幻想主体以独立透明对象叠加，并通过道路消失点、墙面角度、尺度、景深、真实结构遮挡和接触阴影融入空间。Skill 明确禁止先生成完整动画街景再差分去背，也不再默认把人物抠出后贴回，从源头消除人物边缘、背景残片和抠图感。

从 v1.7.0 起，透明素材还必须通过“空间融合合同”：整组元素使用统一线条、色板、明暗和光向；每个对象绑定天空、地面、墙面、台面或建筑后方，并至少具备两种融合机制。新增脚本会检查地面接触阴影、建筑遮挡蒙版、深度清晰度、局部色温和可疑的素材裁切边，避免出现“虽然去背了，但只是贴在照片上”的结果。

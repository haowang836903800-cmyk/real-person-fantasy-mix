# 豆包首轮异质样例

这些样例只演示如何把同一套视觉语法迁移到不同照片。运行时先分析用户当前照片，再选择全新的题材；禁止复制样例中的具体主体、配角和构图。若当前照片与某样例相似，也只能借用推理结构，不能照抄物件清单。

## 样例一：开阔海岸远望

- 摄影底片：真人站在栏杆旁远望；海面、远山、栏杆和午后侧光保持原样。
- 故事动词：启程。
- 主奇观：从海面航迹与风向发展出一座远处缓慢移动的“潮汐帆城”，而不是默认动物。
- 材质同源：轮廓取自船帆和浪线，中间色取自海水，暖色只落在迎光帆面。
- 视觉路径：帆城 → 海上细长航线 → 栏杆上停靠的小信使 → 真人视线。
- 中型元素功能：一个栏杆接触角色、两艘远近不同的小航船、一组沿风向移动的海鸟、一个从栏杆后露出的植物结构。
- 三处融合：植物从栏杆后穿出；接触角色脚底落在栏杆顶面；一段航线被真人轮廓遮住后在另一侧继续。
- 光色：只用帆面迎光作为主光事件；远景更柔，真人不加新光。

## 样例二：繁忙城市街道

- 摄影底片：真人、店面、车辆、路牌、道路透视和阳光方向全部保持摄影。
- 故事动词：引路。
- 主奇观：由窗格、交通线和招牌几何发展出的“折叠城市列车”，沿街道消失点悬行；不复制照片里的品牌或文字。
- 材质同源：车身结构呼应建筑网格，配色取自街景中已有的两种主色和一个低饱和强调色。
- 视觉路径：列车前灯 → 道路透视线 → 一组路边引路角色 → 真人站位。
- 中型元素功能：一个真实路牌后的探头角色、一个车顶停靠伙伴、一组沿车流方向飞行的纸片生物、两处窗内微型世界。
- 三处融合：角色被路牌遮住一半；飞行轨迹从车辆后方消失；窗内世界被真实窗框分割。
- 光色：主光事件是列车经过建筑阴影时的一条暖色窗光；不做满街霓虹和赛博滤镜。

## 样例三：山林步道

- 摄影底片：人物姿势、树木、石阶、山脊、雾气与逆光关系保持原样。
- 故事动词：相遇。
- 主奇观：从树冠与山脊剪影演化出的“枝叶守护者”，身体由扁平叶片层和树影色阶组成，不画真实毛发。
- 材质同源：枝杈方向跟随现场树势，背光色来自山雾，少量暖光来自原太阳方向。
- 视觉路径：守护者低下的视线 → 飘落种子群 → 石阶上的小伙伴 → 真人。
- 中型元素功能：两只石阶停靠伙伴、一簇从岩缝长出的发光蕨叶、一组沿风向移动的种子、远处一个山脊回声结构。
- 三处融合：蕨叶从石缝生长；一只伙伴被台阶边缘遮挡；种子群从树干后消失再出现。
- 光色：只有树冠缝隙形成的局部光路最亮；远景守护者降低对比。

## 样例四：咖啡馆桌边

- 摄影底片：真人、手势、杯盘、桌面、窗户、室内光和浅景深保持摄影。
- 故事动词：守候。
- 主奇观：从咖啡蒸汽与杯沿曲线发展出的“蒸汽天文台”，悬在杯口附近但不遮挡脸和手。
- 材质同源：结构取自杯沿、勺子和窗格，色彩取自咖啡、陶瓷和室内暖光。
- 视觉路径：天文台的旋转轨道 → 蒸汽曲线 → 桌上的微型访客 → 真人视线或手势。
- 中型元素功能：杯碟边缘的观察员、沿勺柄移动的小队、窗框后的一颗微型月亮、桌面上的地图光路。
- 三处融合：观察员脚落在杯碟；轨道被杯口遮住一段；地图光路从手后经过但不覆盖皮肤。
- 光色：主光事件是窗光穿过蒸汽形成的局部亮边；不把整个室内改成幻想插画。

## 迁移检查

使用任何样例后都要重新问：如果把主奇观和中型元素剪下来放到另一张照片，它们是否仍完全成立？若答案是“是”，说明没有真正根据当前场景设计，需要重新生成蓝图。

# 像素安全合成

当用户要求真人必须与原照片完全一致时，提示词不能承担保真任务。使用本流程，让模型只生产幻想素材，让脚本负责最终合成与验证。

## 能力要求

- macOS 可直接使用系统 Vision 生成人物遮罩。
- 合成脚本需要 Python 3 与 Pillow；缺少 Pillow 时执行 `python3 -m pip install Pillow`。
- 幻想素材必须是与原照片同尺寸、同画布定位的透明 PNG。不得把全画幅图生图结果伪装成透明素材。

如果当前环境不能运行脚本、不能生成透明素材，也没有其他可靠的遮罩合成工具，就停止并说明限制，不生成“看起来像原人物”的替代版本。

## 第一步：只生成透明幻想层

根据视觉蓝图把设计拆成两张或更多同尺寸 PNG：

- `fantasy-back.png`：位于真人身后，包括远景主奇观、远处航线和被人物遮住的部分。
- `fantasy-front.png`：位于真人前方但不得覆盖脸、皮肤、头发、服装、手脚和原影子的元素。

提示图像工具：保留原照片画布尺寸和坐标，只输出新增元素，其余区域完全透明。禁止输出完整背景、重新生成的街景或人物。

如果工具不能直接输出透明背景，可在纯色背景上生成素材后去背；去背结果仍必须与原照片画布对齐，并目视检查边缘。不允许使用普通 JPEG 作为幻想层。

## 第二步：生成人物保护遮罩

macOS 上执行：

```bash
sh scripts/macos_person_mask.sh original.jpg person-mask.png
```

遮罩中白色为受保护真人，黑色为可叠加区域。执行后必须查看遮罩；若漏掉发丝、墨镜、包、衣摆、手脚或原影子，用任何普通蒙版工具补成白色，并作为额外 `--protect-mask` 传入。自动分割结果未经查看不得直接用于最终交付。

## 第三步：执行无损合成

```bash
python3 scripts/compose_fantasy.py \
  --base original.jpg \
  --person-mask person-mask.png \
  --back fantasy-back.png \
  --front fantasy-front.png \
  --output final.png \
  --report final-report.json
```

需要保护原影子、重要建筑、文字或标志时，可多次添加：

```bash
--protect-mask extra-protection.png
```

脚本会：

1. 以原照片为底图；
2. 合成后景幻想层；
3. 把原照片人物像素逐像素恢复；
4. 自动从前景幻想层中剔除所有人物保护区域；
5. 再次恢复人物像素；
6. 只输出无损 PNG；
7. 验证保护区域与原照片解码像素完全一致。

透明层覆盖画布超过 60% 时，脚本默认中止，防止代理偷偷使用整图重绘。确有大型、透明且合理的天空奇观时，只有在目视确认该文件仍是纯幻想 RGBA 层后，才能谨慎调整 `--max-overlay-coverage`。

## 第四步：硬验收

只有脚本输出 `status: PASS`、`changed_protected_pixels: 0` 和 `protected_pixels_exact: true` 才能交付。最终文件必须是 PNG。

报告中的“完全一致”只针对提供的保护遮罩。遮罩漏选区域不会被验证，因此查看并补全遮罩是强制步骤。不得把自动遮罩的成功运行等同于完整保护。

## 禁止路径

- 禁止把整图图生图成品作为 `--back` 或 `--front`。
- 禁止用第二次生成修复人物。
- 禁止输出 JPEG 后声称像素一致。
- 禁止把“肉眼相似”“基本没变”“只有细微差异”判为通过。
- 禁止为了制造穿插而让幻想层覆盖人物；应把相应段落拆到后景层。

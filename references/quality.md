# 成图检查

把原图与成图并排查看，并按优先级检查。

## 1. 真人是否仍是摄影

- 五官、脸型、发际线、眼镜、皮肤明暗是否对应原图。
- 衣服是否仍有真实织物、褶皱与原有图案，而不是纯色色块。
- 是否出现黑色描边、白色贴纸边、平涂皮肤或不属于原图的肢体。
- 姿势、比例、裁切和影子是否变化。
- 皮肤毛孔、发丝、眼睛、牙齿、手脚、衣料和首饰是否保留原图细节，而不是被 AI“修漂亮”。
- 人物区域的锐度、景深、颗粒、压缩纹理和噪点是否与原摄影一致，轮廓是否出现光晕、硬边或颜色渗漏。

允许整张照片做统一调色，但调色不能抹掉人物的局部明暗、肤质、衣料或相机纹理。人物不只是“明显插画化”才算失败；任何生成式重绘、美颜、磨皮、五官或发丝重建、虚构补光、身体轮廓漂移和摄影纹理不一致都不能通过。优先把人物遮罩用作幻想层的禁止绘制区，始终保留完整原照片；不要默认抠出人物再贴回。

## 2. 场景是否保留

核对建筑外轮廓、栏杆方向、地平线、岩石形状、道路消失点、景深和光线。轻微颜色变化与明显结构重绘要分开判断。

## 3. 插画层是否纯粹

幻想元素应是二维色块与简洁轮廓，不应出现塑料高光、黏土体积、写实毛发或真实摄影动物。

高质量不等于 CG 发光。若主体呈现半透明金色玻璃、线框体积、游戏光轨、网文漫剧海报或重复素材图标，即使分辨率高也判定失败。合格幻想层应有二维色面、四层光色、结构性细节、边缘软硬和安静区域。

## 4. 空间互动是否可信

至少检查三处遮挡或接触点。确认“在后”的部分确实被真实人物或物体遮住，“在前”的部分连续可见；不要让飘带穿进脸、栏杆切断角色或植物悬浮在没有落点的位置。

豆包默认用建筑、栏杆、墙角、道路、台阶、水面和地平线建立遮挡，不强求人物参与穿插。检查每张幻想素材：单独查看时只能看到孤立对象与透明背景；若能看到重绘建筑、道路、天空或完整插画场景，即使人物像素未变也判定失败。

再执行 [空间融合合同](spatial-integration-contract.md)：同一画面的幻想对象必须属于同一套线条、色板、明暗和角色成熟度；每个对象至少使用两种融合机制。尤其检查底部是否出现水平裁切线，地面对象是否有接触阴影，建筑后方对象是否真的被屋顶或墙角遮挡，远景是否降低锐度和饱和度。只完成抠图、缩放和粘贴不通过。

检查素材来源：优先使用同一次生成的统一素材表。若素材文件仍有粉色渐变底、白边、黑边、彩色溢出、背景光晕或透明噪点，不得以“已经是 RGBA”放行。

## 5. 主次与丰富度

大型主体在缩略图中可辨，中型元素承担情节，小细节只连接节奏。人物仍是故事主角，关键场景锚点没有被遮没，也没有变成满屏同尺寸贴纸。

再检查题材是否真的由当前照片推导：主奇观至少在形态、色彩或运动三项中有两项呼应现场；4—6 个中型元素各有空间或叙事功能；视觉路径能从奇观回到真人。若只是照搬参考案例的鲸鱼、花丛、纸飞机或动物组合，即使画得精致也不通过。

## 6. 可选电影奇想模式

若启用了“澄澈电影奇想”，再检查：奇观是否来自真实天气或地点锚点；光色是否服从原照片而非统一滤镜；是否形成近景接触、中景人物、远景奇观；负空间是否足够；是否避免动漫化真人、通用紫粉天空、过量泛光与可识别作品模仿。未启用时跳过本项。

## 报告边界

可以报告实际生成方式、尺寸、可见的空间关系和已知局限。不能把普通图生图称为逐像素无损、独立图层或可编辑 PSD。

若使用像素安全合成，必须同时交付 PNG 与 JSON 验证报告；报告需显示 `changed_protected_pixels: 0`。若最终文件为 JPEG，或说明中出现“人物可能有细微差异”，一律判定没有完成严格真人锁定。

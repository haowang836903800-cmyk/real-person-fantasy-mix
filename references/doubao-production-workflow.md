# 豆包分层制作流程

本流程只在豆包运行时启用，用于解决两个高频问题：整图编辑会悄悄重新生成人物；只写“高级插画”容易得到扁平 TV 卡通。核心原则是把真人保真与幻想审美拆成两个独立问题：原照片负责真人与实景，生成模型只负责幻想层。

## 生成前先选执行模式

按工具能力从上到下选择第一个可用模式。不要先做整图生成再补救。

### A. 原照片底图 + 独立幻想层 + 遮挡蒙版（首选）

1. 原照片作为不可变底图；人物、建筑、道路、山水、天气和摄影纹理不进入生成流程。
2. 单独生成幻想主体和中小元素，优先使用透明背景；不支持透明时使用便于去背的纯色背景，且幻想元素不得带白色贴纸边。
3. 从原照片提取人物遮罩与需要参与遮挡的真实物体遮罩，例如栏杆、岩石、墙沿和树枝。
4. 按“底图 → 后景幻想 → 真实物体/人物遮挡层 → 前景幻想”的顺序合成，制造至少三处真实穿插。
5. 接触阴影、反射或局部光雾只能添加在人物遮罩之外；不重新照亮、磨皮或重画人物。
6. 最后可以对完整合成做一次统一、非生成式调色。人物始终来自原图像素。

### B. 受保护区域的局部生成

工具支持遮罩编辑但不支持独立图层时：

- 把人物、原影子和关键地点锚点全部设为保护区，并留出包含发丝细边的安全边界。
- 只开放天空、水面、空墙、道路或其他计划放置幻想元素的区域。
- 一次生成只解决既定幻想构图，不使用“整图变得更电影、更梦幻”之类会触发全局重绘的指令。
- 生成后只要保护区发生任何变化，就判定此模式失败，切换到模式 A。

### C. 只有整图生成、没有遮罩或合成

此能力无法可靠满足严格真人锁定。不要继续用不同提示词反复整图生成，也不要把“很像本人”当成通过。

如果工具可以单独生成素材，就生成幻想层素材并交给具备抠图/合成能力的工具；否则明确说明当前工具无法同时保证人物原样与复杂幻想融合。不能为了完成任务而交付被重新生成的人物。

## 豆包电影光影构建法

目标是原创的澄澈、辽阔、情绪化电影画面，不在提示词中写任何艺术家、动画电影或“同款风格”名称。

在进入以下步骤前，必须先完成 [豆包首轮视觉语法](doubao-v5-visual-grammar.md) 的八项蓝图。该蓝图是生成前置条件，不是生成后的复盘表。

### 1. 一个情绪动作

从等待、远望、相遇、启程、穿越、告别或归来中选一个。人物原动作不变，幻想元素的运动方向、距离和节奏回应这个动作。

### 2. 一个主光影事件

只选一个：云层边缘被真实阳光照亮、幻想生物内部透出暖光、天空航道穿过云缝、水面承接一条远方光路，或阴天中出现局部柔和亮区。光向必须与照片一致，不能给真人添加新轮廓光。

### 3. 三层空气纵深

- **近景**：真实栏杆、岩石、枝叶或地面接触点，边缘最清楚，负责遮挡与落地。
- **中景**：原照片人物和少量互动元素，保持摄影锐度与原景深。
- **远景**：大型奇观与天气层，降低对比和饱和度，轮廓部分融入空气，但主体剪影仍可辨。

### 4. 幻想主体的二维光色层次

每个主要区域至少组织为基础色、迎光面、背光面和少量通透强调层。使用细腻平涂、受控柔和渐变、透明叠色与局部颗粒；不要统一粗黑轮廓，也不要只有一块纯色。边缘处理应有层级：接触点和视觉焦点清晰，背光与远景边缘更柔，内部细节沿形体和运动方向排列。

这仍是二维手绘幻想层：禁止照片级云体、写实动物毛发、3D 塑料高光、黏土体积和游戏 CG 渲染。

### 5. 色彩脚本

从原照片提取主环境色和明亮中性色，再选择一个与情绪有关的暖色或冷色强调。大部分画面延续原摄影色，幻想中间色建立层次，最亮强调只集中在主奇观和视觉路径。不要用全图紫粉晚霞、蓝橙滤镜或高饱和渐变制造假电影感。

### 6. 摄影融合

- 幻想元素服从原透视、地平线、镜头方向和真实光源。
- 根据其所在深度匹配清晰度、景深和空气对比；远景不能比人物更锐。
- 只给幻想层匹配适量颗粒、压缩纹理和色温，不处理原人物。
- 接触阴影必须落在真实承托面上，并保持轻、软、方向正确；不把阴影画到人物皮肤和衣服上。

## 强风格参考的用法

若用户提供一张已认可的成图，可将其作为唯一风格参考，只提取幻想层的光色层次、边缘软硬、细节密度、主次、视觉路径、接触方式和空气感。不得复制参考图中的人物、服装、地点、构图、文字、品牌、鲸鱼、花丛、动物、飞行器或其他具体幻想角色。没有参考图时，使用本文件与“豆包首轮视觉语法”的可测量规则，不用艺术家姓名替代。

## 首轮提示词编译器

豆包第一次生成前，按以下顺序把蓝图转换成具体句子。每一段都必须绑定当前照片中的名词，不能只剩抽象形容词：

1. 用真实对象列出摄影底片保护范围。
2. 用一句话写“人物正在做什么 + 幻想世界如何回应”，不改变人物动作。
3. 写主奇观的原型、环境材质来源、比例、位置、运动方向和四层二维光色。
4. 逐条写 4—6 个中型元素的功能、位置与动作；禁止只罗列名词。
5. 逐条写三处遮挡、承托或穿插，并说明前后关系。
6. 写视觉路径、三层空气纵深、密度地图和唯一主光事件。
7. 最后写禁止项、原比例与最高原生质量。

如果某段出现“参考案例同款”“像上一张那样”或只写“更高级、更电影、更梦幻”，必须展开为可观察的画面规则后才能生成。

## 豆包电影感提示词模块

把以下内容放在人物底片锁定和具体故事之后、负面约束之前：

```text
新增内容采用原创的澄澈电影光影二维手绘语言，只生成幻想层，不风格化真人和实景。画面由近景真实接触点、中景摄影人物、远景大型奇观构成三层空气纵深。设置一个明确且符合原照片光向的光影事件：【填写光影事件】。幻想主体使用基础色、迎光面、背光面和少量通透强调层，以细腻平涂、受控柔和渐变、透明叠色和局部颗粒形成丰富层次；主焦点与接触点边缘清晰，背光和远景边缘更柔。色板从原照片取色，以一个克制强调色引导视线，最亮区域只集中在主奇观和视觉路径。整体明亮、通透、辽阔、安静而有故事感，保留负空间与巨大尺度反差；不是扁平 TV 卡通，不是纯色色块贴纸，不靠紫粉天空、蓝橙滤镜、泛光和满屏粒子制造电影感。保持二维手绘，不做写实幻想生物、3D 或游戏 CG。
```

## 交付前硬门槛

- 人物必须能与原图轮廓和细节稳定对应；任何重新生成迹象直接失败。
- 原照片的建筑、道路、山水、天气、透视和摄影纹理仍然存在，没有变成动画背景。
- 主奇观有明确光影层次、空气透视与边缘软硬，不是单色贴纸。
- 至少三处穿插由真实人物/物体遮罩完成，而不是让生成模型重画人物。
- 只有一个主光影事件和一个主要情绪动作；其余细节服务它们。
- 题材与当前照片有关，未机械复刻参考案例的鲸鱼、花丛、纸飞机或元素组合。

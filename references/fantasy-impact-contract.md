# 幻想强度合同

本合同解决“人物保住了、素材也去背了，但成图只剩几枚小贴纸”的失败。先判断画面是否真的发生了幻想事件，再判断素材是否精致。空间融合不能代替幻想强度。

## 一个主事件，而不是一组装饰

每张图先用一句完整句子写出主事件：**什么不可能的事，正在借助照片里的什么真实结构发生，并如何回应人物。**

合格例子只描述逻辑，不限定题材：

- 一座由窗格节奏生长出的巨大城市伙伴从两栋楼后探身，沿道路方向为人物引路；
- 一条由海浪形态演化的空中航道从真实海面升起，绕过山脊后通向人物视线；
- 一株巨型植物从真实石缝长出，枝叶穿过栏杆并在建筑背后重新出现。

“空中有一辆电车、旁边有纸飞机和光点”不构成主事件；它只罗列物件，没有尺度奇观、因果、空间动作或人物关系。

## 主奇观硬指标

- 恰好一个 `main` 主奇观；它在 25% 缩略图中必须不经放大就能辨认。
- 主奇观放置后的包围盒宽度至少占画布 28%，或高度至少占画布 22%。其可见非透明像素至少占画布 2.5%。
- 主奇观必须发生一种明确的“不可能变化”：巨大化、生命化、空间折叠、跨介质生长、天气实体化、建筑变形或超现实运动。普通物件以正常大小悬浮不算。
- 主奇观必须至少与一个真实结构发生遮挡或与一个真实承托面发生接触；仅做色温、透明度、模糊、辉光不算。
- 主奇观不能完整悬在空白天空中。至少一段轮廓被真实楼体、山脊、树枝、栏杆、桥梁或其他现场结构挡住，或者真实落在道路、台阶、水面、屋顶等承托面上。
- 主奇观的形态、色彩、运动三项中至少两项来自当前场景；换到任意照片仍成立的通用素材判定失败。

## 情节链硬指标

- 除主奇观外安排 4—6 个 `support` 中型情节组；一群沿同一路径运动的小对象可作为一个组。
- 每个中型组都要写 `narrative_relation`，说明它如何连接主奇观、真人或真实场景，不能只写名词。
- 全画面至少有三个不同对象通过真实遮挡或接触阴影参与空间；调色、景深与发光不能凑数。
- 4—6 个中型组必须共享同一主事件、运动路径和风格系统。随机加入纸飞机、泡泡、星星、光点不算丰富。
- 全部幻想层可见像素至少占画布 4%，否则通常只是小装饰；同时不得淹没人物或地点锚点。

## 三秒检验

把成图缩至长边约 320 像素，连续回答：

1. 三秒内能否说出发生了什么不可能的事？
2. 能否一眼指出唯一主奇观，而不是在多个小物件中寻找？
3. 主奇观是否明显属于这个地点，并与真人处在同一个故事中？
4. 去掉纸飞机、光点等装饰后，主事件是否仍然成立？

任一答案为“否”，不得交付。扩大一个普通素材也不能自动通过；应重新设计主事件与真实结构关系。

## 清单字段

空间清单顶层必须提供：

```json
{
  "story": {
    "verb": "引路",
    "fantasy_event": "由街道窗格生长出的巨大城市伙伴从楼后探身，沿道路引导真人前行",
    "visual_path": "主奇观视线—沿楼体灯带—道路消失点—真人",
    "person_relation": "幻想世界朝真人的行进方向回应，不改变真人动作"
  },
  "style_group": "single-cinematic-2d-system"
}
```

每个对象必须标注 `role`、`anchor` 与 `narrative_relation`。`main` 还必须标注 `impossible_change`。这些字段不是报告文案，而是生成与合成前的设计依据。

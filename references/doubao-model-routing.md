# 豆包生图模型与质量路由

本文件只在豆包运行时启用。模型名称会随产品更新而变化，因此不要把某个版本号永久写死；每次任务都要先读取当前可用的图像工具与模型，再按能力选择。

## 生成前置检查

在任何图像生成调用之前：

1. 枚举当前豆包环境可用的静态图像生成、图像编辑与透明素材生成工具。
2. 在可选模型中选择发布时间最新、质量档最高、支持图像参考或局部编辑的正式静态生图模型。
3. 如果同一模型有“高质量 / 精细 / 专业 / 慢速”和“快速 / 极速 / 草稿 / 省时”档，必须选择最高质量档。
4. 选择工具支持的最高合理原生分辨率；不要先用低清图生成后反复锐化。
5. 记录实际调用的工具名、模型名、质量档和原生尺寸。不得只写“已使用最新版”而不给实际名称；工具不暴露名称时，明确记录“运行时未暴露模型名”。

## 禁止路由

不得使用以下能力制作最终幻想层：

- 漫剧、网文封面、漫画短剧、条漫或角色海报专用模式；
- 视频生成模型的单帧截图或视频首帧；
- 极速、草稿、预览、轻量或低成本模式；
- 3D、游戏资产、黏土、公仔、写实角色重绘模式；
- 会把整张输入照片统一风格化的滤镜或模板。

若当前环境只提供上述能力，停止并说明无法达到本 Skill 的质量门，不用错误模型勉强交付。

## 幻想层的目标渲染语言

把下列内容作为可观察的绘制要求，而不是只写“高级、电影感、动画感”：

- 高分辨率二维手绘插画，环境结构清楚，细节经得起放大；
- 大形准确，内部使用基础色、迎光、背光和通透强调四层组织；
- 颜色过渡细腻但仍能看出二维绘制面，不是玻璃、金属或塑料体积；
- 焦点与真实接触点边缘清楚，远景、背光与天气边缘柔和；
- 光线明亮通透但有节制，只有一个最亮核心，不给所有物体统一套金边；
- 植物、云层、建筑和小角色具有结构细节，不用重复图标、随机噪点或素材化花纹填充；
- 幻想层匹配照片的透视、空气、景深和色温，但不重绘摄影底片。

## 漫剧感拦截

出现以下任一特征即失败：

- 真人变成网感精修脸、统一光滑皮肤、尖锐下颌、夸张唇眼或海报式轮廓光；
- 幻想主体像半透明玻璃、金色线框、游戏 CG、舞台装置或网文封面特效；
- 地面出现大面积霓虹轨迹、能量环或无物理来源的金色光带；
- 小元素以同形同色重复，像素材包、表情贴纸或批量复制图标；
- 全画面同时发光、同时锐化、同时高饱和，没有安静区域和空气层次；
- 建筑与街景被重绘成漫画背景，真实路人、文字、砖石和透视细节消失。

失败后不能改用更强的“动画、漫剧、电影海报”关键词。应回到透明幻想层，降低 CG 发光，增加二维色面、结构笔触、边缘层级与场景取色，再做一次局部素材生成。

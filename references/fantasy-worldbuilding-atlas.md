# 奇幻世界构建图谱

本图谱负责扩大题材、世界观与视觉冲击上限。它不是元素菜单，也不是要求把东方、西方符号同时堆进一张图。每次只选择一套主导世界法则，再让奇观从照片中的天气、建筑、水体、道路、室内结构或物件自然生长。

## 核心原则

- 扩张的是**世界机制**，不是贴纸数量。先回答“这个现实世界突然遵守了什么新法则”，再设计角色与装饰。
- 一张图只保留一个宏观奇观、一个主导文化语法、一个主要材质系统和一条视觉路径。其余元素为它服务。
- 真人与实景仍是摄影层；奇幻层可以大胆、光怪陆离、跨尺度，但不能靠重画人物或抹掉地点来制造冲击。
- 文化灵感用结构、材质、节奏和空间观表达，不把神圣文字、宗教法器、民族服饰或具体神祇当作随意装饰。
- 不用艺术家姓名、影视 IP、游戏角色或可识别作品作为风格捷径。

## 四轴生成法

为当前照片各选一项；必要时可在同一轴内混合两项，但不要让所有轴同时复杂化。

### 1. 文化与叙事语法

#### 东方奇谭语法

- **山水天境**：云海分层、远近留白、山脊化为航道、亭台与桥从雾中显现；适合山水、湖海、大天空。
- **灯火夜游**：灯河、纸灯生物、夜行队列、檐下小灵、倒影城；适合夜景、街巷、窗景、水边。
- **纸墨异界**：宣纸裂隙、墨潮、折纸飞行物、印章花、卷轴路径；适合室内墙面、书店、咖啡馆、极简建筑。
- **丝绸风场**：长绸化作风、桥、河流或生物躯体，在真实结构前后穿行；适合人物朝向明确、栏杆或建筑线条强的画面。
- **漆金灵兽**：使用原创的鹿、鸟、兔、鱼、狐、龙形或混合轮廓，以漆红、玉色、铜金、云纹节奏构成；避免复刻具体神兽图像。
- **机关天城**：檐角、斗拱、天文仪、悬桥、云梯和漂浮楼阁组成可运行的天空城市；适合古今建筑、城市天际线与大型室内空间。

#### 西方秘境语法

- **彩窗圣光**：彩色玻璃般的动物、花园或光路被真实窗框、拱门与建筑切割；不复制宗教人物或特定教堂图案。
- **星象炼金**：星盘、轨道、黄铜仪器、元素容器、天体花园与月相机械；适合屋顶、夜空、书房、工业建筑。
- **哥特生长**：尖拱、飞扶壁、蔷薇窗、石兽轮廓从现实建筑或树枝中变形长出；保持原创结构，不复刻地标。
- **妖精生态**：发光菌群、微型门廊、枝叶城市、花粉航路和尺度错位的植物伙伴；适合森林、公园、花园、桌面。
- **巴洛克巡游**：帷幕、金饰、面具、舞台机械与盛大队列形成强方向感；适合婚礼、剧场、宴会与宫殿空间。
- **航海传说**：星图帆船、风之港、云海舰队、灯塔生物与潮汐之门；适合海岸、港口、桥梁与远景城市。

#### 跨文化原创语法

- **天空海洋**：云层成为海面，鱼群、潮线与岛屿在天空运行。
- **活体建筑**：建筑像植物、乐器、骨骼或机械一样生长，但保留真实建筑识别锚点。
- **玻璃荒原**：透明山脉、折射河流、漂浮碎片和棱镜天气进入城市或自然空间。
- **时间花园**：季节、昼夜、旧照片、影子或钟表以空间层叠形式同时出现。
- **星际民俗**：将日常市集、车站、节庆、咖啡馆或街道扩展为原创宇宙社区，而不是套用科幻 UI。
- **梦境交通**：云轨、鲸舟、花瓣列车、月门、折叠楼梯或倒流瀑布成为人物与奇观之间的叙事路径。

### 2. 奇观原型

从以下原型中选一个作为主奇观，避免连续作品重复同类主体：

1. 巨型生物或群体生命
2. 漂浮城市、车站、花园或宫殿
3. 天空河流、海洋、瀑布或潮汐
4. 巨型植物、晶体、菌群或气象生命
5. 旋转星盘、天体机械或时间装置
6. 贯穿场景的桥、轨道、阶梯或光路
7. 建筑觉醒、折叠、开花或变形
8. 镜面世界、影子世界或倒影叛离现实
9. 盛大巡游、迁徙、夜航或归来队列
10. 门、裂隙、幕布、云缝或水面开启的异界

### 3. 世界法则

只选一个主要法则；它决定全图的因果关系。

- **尺度倒置**：日常物变成城市，微小生物变为地貌。
- **重力改写**：水、花瓣、道路或建筑向天空流动。
- **材质苏醒**：云、砖、玻璃、食物、纸张或灯光获得生命。
- **空间折叠**：窗、桥洞、镜面、门缝把远近空间连接起来。
- **时间并置**：同一地点的清晨、夜晚、季节或年代在不同层面同时出现。
- **倒影独立**：水面、橱窗、镜子或地面反光拥有自己的奇幻事件。
- **天气具象**：风、雨、雾、雷、雪或阳光形成生物、建筑或路径。
- **路线显形**：人物的视线、动作、道路、栏杆或光束显露出隐藏交通系统。

### 4. 材质系统

选一主一辅，维持统一完成度：

- 漆色 + 金线
- 宣纸 + 墨色
- 丝绸 + 半透明光
- 玉石 + 云雾
- 青铜 + 星光
- 彩色玻璃 + 投影光斑
- 黄铜机械 + 深蓝夜空
- 石雕 + 苔藓植物
- 珐琅 + 珠光
- 晶体 + 折射水汽
- 花瓣 + 水彩色块
- 霓虹薄膜 + 城市反光

## 场景路由

- **大天空、山水、海面**：优先天空海洋、天境、航海传说、天气具象、漂浮城市、迁徙或巨型生物。主奇观可占可用留白的 30%–50%。
- **城市街道、桥梁、广场**：优先梦境交通、机关天城、建筑觉醒、巡游、路线显形。沿道路消失点组织尺度变化。
- **古建筑、园林、寺观周边**：优先山水天境、丝绸风场、原创漆金灵兽、灯火夜游；不要伪造可读匾额、经文或宗教仪式。
- **欧洲建筑、老城、教堂外观**：优先彩窗圣光、星象机械、哥特生长、妖精生态；不复刻特定宗教人物与纹章。
- **室内、酒店、咖啡馆、商店**：优先纸墨异界、微型世界、镜面独立、物件苏醒、巴洛克舞台或时间花园。必须利用窗、墙缝、灯带、桌沿、镜框、沙发、杯碟等真实接触面。
- **婚礼、舞台、派对**：优先花之交响、星象舞台、帷幕巡游、灯火夜游或时间花园。奇观要回应真实灯光、帷幔、花艺、麦克风和反射地面。
- **食物与桌面**：优先微型城市、香气天气、食材生态或餐具交通系统；避免把食物只加眼睛变成低幼角色。

## 全画面世界构图

不要把奇观限制在一块空白墙或天空角落。先把输入照片划分为 4–7 个真实区域，例如天空、建筑、人物、地面、窗户、反射、水面、前景物体。然后建立一条贯穿至少三个区域的因果链：

`起源锚点 → 主奇观 → 人物关系 → 次级空间 → 回声/倒影`

示例：

- 云缝开启 → 天空列车出现 → 轨道经过人物身后 → 落到真实屋顶 → 在水面形成倒影。
- 窗外月门打开 → 丝绸生物进入室内 → 从人物身后穿过 → 沿灯带抵达墙面 → 在地板留下光迹。
- 建筑拱门开花 → 巨型植物越过屋顶 → 小角色攀住真实栏杆 → 花粉沿道路远去 → 橱窗中出现另一层世界。

若安全或工具限制使整图无法一次生成，可把全画面的同一世界观拆成多个背景区域分别生成，再按原坐标合成。分区不等于局部贴画：每个区域必须共享同一主体、方向、材质、光源与故事路径，人物区域保持原图像素。

## 视觉冲击档位

- **克制奇遇**：主奇观占可用空间约 20%–30%，中型元素 3–4 个，保留大量摄影留白。
- **电影奇观（默认）**：主奇观占约 30%–50%，中型元素 4–6 个，贯穿 3–5 个真实区域，存在清晰的光色事件与尺度反差。
- **光怪陆离**：主奇观可占约 45%–65%，使用强烈尺度倒置、空间折叠或天气具象；中型元素仍不超过 6 个，所有细节沿同一世界法则组织。用户明确要求“更炸裂、更多奇幻、视觉冲击”时启用。

“光怪陆离”不等于满屏发光、饱和紫粉、无限粒子或同时出现十种神兽。冲击力应来自一个清晰的大剪影、一个违反现实但自洽的世界法则、跨区域的空间关系和真实尺度参照。

## 防重复与原创性

生成前检查最近作品或当前会话：若连续出现兔、鲸、鹿、花海、纸飞机、月亮、列车或同类配色，主动换到不同奇观原型、文化语法、世界法则与材质系统。不要因为样例成功就固化题材。

主奇观必须满足以下三项中的至少两项：

- 形态来自当前场景的真实轮廓；
- 材质或色彩来自当前照片；
- 运动方向来自人物视线、道路、水流、云势、建筑线或光束。

如果移除原照片后，剩下的奇观仍可无差别贴到任何照片上，则设计不合格。


## 失败拦截

- 东方与西方符号无因混搭，像素材市场拼贴；
- 只更换神兽或建筑名称，构图逻辑仍完全相同；
- 主奇观没有起源锚点、运动方向或落点；
- 画面局部很华丽，但其余区域没有故事回声；
- 为制造冲击遮住人物、地标或真实透视；
- 用高饱和、泛光、粒子和镜头光斑代替世界构建；
- 加入伪文字、假经文、随机符号、宗教人物或不准确文化标记；
- 同时出现多个互相竞争的大型主体；
- 新增元素无法解释为什么只会出现在这张照片中。

# 空间融合合同

“透明背景”只解决素材能否叠加，不能保证它属于照片空间。每一个幻想对象在进入最终画面前，都必须签订一份空间融合合同；缺少落点、透视、光线和真实遮挡的对象就是贴纸。

## 先统一整组素材

同一张成图中的所有幻想对象应使用同一张风格锚点或一次性资产表生成，保持：

- 相同的线条粗细与边缘处理；
- 相同的明暗层数、材质颗粒和笔触密度；
- 相同的主色板与强调色；
- 相同的光源方向和色温；
- 相同的角色成熟度，不能同时出现绘本儿童、半写实动物、折纸图标和水彩装饰。

优先一次生成包含全部对象、对象彼此分离且四周留透明余量的资产表，再分别抠取。若分开生成，每次必须使用同一个风格锚点与完全相同的渲染说明。

## 每个对象必须回答六个问题

1. **空间平面**：它属于天空、地面、墙面、台阶、栏杆顶面还是建筑后方？
2. **真实锚点**：它具体落在哪条边、哪个砖缝、哪块路面或哪栋建筑之后？
3. **尺度依据**：它相对附近门、车、人、栏杆或窗户有多大？
4. **深度处理**：它处于近、中、远哪一层，对比、饱和和清晰度如何随距离变化？
5. **光线响应**：迎光面、背光面和接触阴影是否服从原照片？
6. **融合机制**：至少使用下面两种机制，其中地面与台面对象必须有接触阴影，建筑后方对象必须有遮挡蒙版。

## 融合机制

- **真实结构遮挡**：让部分插画被建筑屋顶、山脊、树枝、栏杆、路牌或桥梁挡住；不是把对象完整放在空白区域。
- **接触阴影**：脚、轮子、花盆或身体底部在承托面产生轻而方向正确的阴影；不能使用素材自带的粉色或白色背景阴影。
- **局部色温适配**：从落点附近取一个环境色，以 5%—15% 的透明色影响幻想对象；不套全局滤镜。
- **深度适配**：远景降低对比、饱和与锐度，中景轻微柔化，近景保持清楚；不能让远处小对象比真人更锐。
- **透视尺度**：同类对象沿道路或建筑消失点逐渐缩小，间距也随深度压缩。
- **空气与反射**：天空远景可有极轻空气雾，水面或玻璃对象可有局部反射；只在照片确实存在相应介质时使用。

## 可接受的风格反差

二维插画可以明显区别于摄影，不必伪装成真实物体；自然融入来自空间关系，而不是写实材质。醒目的大色块可以保留，但必须看起来“长在建筑后、坐在台面上、从树枝间穿过或沿道路远去”，不能像完整贴纸漂浮在照片表面。

## 贴纸感硬失败

出现以下任一情况就停止合成：

- 对象完整轮廓四周都可见，没有任何真实遮挡或接触；
- 底部是被裁切的水平直线、矩形边或素材画布边；
- 对象自带与照片无关的纯色底、彩色光晕、白边或黑边；
- 地面角色没有接触阴影，脚底悬空或影子方向错误；
- 远近对象大小相同、锐度相同、饱和度相同；
- 同一画面混入两种以上明显不同的插画体系；
- 中小元素只是散落在空白处，没有共同的运动路径或故事关系；
- 只把元素缩放、旋转、粘贴，没有做色温、景深、阴影或遮挡。

## 可执行流程

1. 先执行 [幻想强度合同](fantasy-impact-contract.md)，确定一个足够醒目的主事件，再生成一套风格统一、四周留透明余量的独立素材。
2. 为真实建筑、山脊、栏杆或树枝制作需要的遮挡蒙版。
3. 创建空间清单，填写故事、统一风格组，以及每个对象的 `role`、`anchor`、`narrative_relation`、`space`、`depth`、真实坐标、尺寸、色温、阴影和遮挡蒙版。
4. 使用 `scripts/build_spatial_layer.py` 生成画布对齐的透明空间层；脚本会拒绝主奇观过小、支持情节不足、真实物理关系不足、缺少关键融合机制和碰到素材边界的可疑裁切。
5. 使用 `scripts/compose_fantasy.py` 将空间层作为 `--overlay` 叠加到底板；人物安全区仍须零相交。
6. 在 25% 缩略图和 100% 视图各检查一次：缩略图看主次与空间，100% 看边缘、阴影、色温和遮挡。

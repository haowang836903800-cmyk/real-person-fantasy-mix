# 豆包首轮视觉语法

本文件只在豆包运行时启用。它来自一次已认可成图的反向分析，但只保留可迁移的画面逻辑，不保留鲸鱼、花丛、纸飞机或任何具体题材。目标不是复刻案例，而是让不同照片第一次生成时就具有同等级的完整度、电影感与空间融合。

## 先建立蓝图，再写提示词

在调用图像工具前，必须先在内部完成下面八项蓝图。不得跳过蓝图直接从“梦幻、电影感、高级”之类形容词开始生成。

1. **摄影底片**：列出真人保护区、地点锚点、地平线、原光向、可编辑负空间和至少两个真实承托面。
2. **故事动词**：只选一个，例如相遇、远望、启程、守候、引路、穿越或归来。新增元素都要服务这个动词。
3. **主奇观原型**：根据场景选生物、植物、飞行物、路径、建筑结构或自然现象之一；不得默认鲸鱼，也不得把案例物件当模板。
4. **场景材质来源**：说明主奇观从照片中的哪种视觉材料获得形状与色阶，例如云层、海浪、树冠、霓虹、砖石、蒸汽、窗格或食材。
5. **视觉路径**：设计一条从主奇观经过中型元素、最后抵达真人或真人视线方向的连续曲线、光路、队列或运动轨迹。
6. **三层空间**：近景真实接触、中景真人互动、远景主奇观；每层至少一个功能明确的元素。
7. **三处融合关系**：写清真实物体遮住什么、幻想元素落在哪里、哪一段从后方消失并在前方重现。
8. **光色脚本**：从原片提取环境主色，指定一个强调色和唯一主光事件；禁止先套固定蓝粉、橙青或彩虹滤镜。

蓝图中任何一项为空，先补齐再生成。

## 被认可效果的抽象特征

### 1. 主奇观是完整角色，不是剪影贴纸

- 缩略图中一眼可见，通常占可编辑负空间的 30%—45%，但不遮人物面部和地点标志。
- 外轮廓清楚而有大形变化，内部沿形体和运动方向组织细节。
- 至少包含四个二维绘制层：基础色、迎光层、背光层、通透或高光强调层。可使用细腻平涂与受控柔和渐变，但不能变成照片级生物或 3D 模型。
- 一部分边缘融入天气或远景，一部分焦点边缘保持清楚；不能全身同样锐利，也不能套统一发光描边。

### 2. 幻想元素从场景长出来

主奇观应同时满足以下三项中的至少两项：

- **形态同源**：轮廓节奏来自现场材料，例如云团、浪线、树冠、建筑几何或蒸汽。
- **色彩同源**：中间色来自照片，强调色只用于焦点和视觉路径。
- **运动同源**：运动方向顺着风、海岸、道路、栏杆、楼体或人物视线。

“放在空白处”不等于融合。若主体可以完整剪下贴到任何照片而不违和，说明设计失败。

### 3. 中型元素组成一条故事链

配置 4—6 个中型元素，但先分配功能，再决定物件：

- 一个负责真人附近的陪伴或回应；
- 一个落在真实承托面上；
- 一个从真实结构后探出或被遮挡；
- 一个负责把视线引向主奇观；
- 一个成群运动，解释风向、速度或尺度；
- 可选一个远景目的地或回声元素。

物件必须依据照片重新选择。不要每次机械加入动物、纸飞机、花和泡泡，也不要把同一案例的组合复制到其他场景。

### 4. 细节有密度地图

- 最高密度：真人附近的接触点、主奇观的脸或核心结构、视觉路径转折处。
- 中密度：连接主奇观和真人的中型元素。
- 低密度：大面积天空、水面、墙面或道路呼吸区。
- 小细节以 3—7 个为一簇，沿运动路径成组出现；禁止均匀撒满星星、泡泡、光点或花瓣。

“丰富”是关系多、层级多、可探索，不是图标多。

### 5. 电影感来自光线组织，不来自滤镜

- 只有一个最亮核心和一个主要光影事件。
- 幻想层的迎光、背光和投影方向服从原照片；不得给真人虚构轮廓光。
- 远景降低对比、饱和与边缘锐度；接触点比悬浮远景更清楚。
- 高光集中在主奇观与视觉路径，其他元素降低一级，避免全画面同时发光。
- 全图统一调色可以连接摄影与插画，但真人仍使用原照片像素与纹理。

### 6. 成熟二维手绘的边缘与笔触

- 以清楚大形、细腻色阶和少量可见笔触为主；不是粗黑线包住纯色色块。
- 焦点边缘偏硬，远景与背光边缘偏软；接触点可有极轻的落地阴影。
- 允许透明叠色、柔和色阶和局部光晕，只服务形体与空间；禁止塑料高光、3D 体积、游戏 CG、低幼绘本描边。
- 插画清晰度需能承受放大查看：轮廓无毛边，色阶无脏块，花叶、羽片、云团等细节有结构而非随机噪点。

## 题材生成器

根据照片先选“环境族”，再从多个原型中择一。下列内容是选择逻辑，不是固定清单：

- 天空 / 海岸：漂浮生物、云中交通、光路、天气建筑、潮汐伙伴。
- 山林 / 花园：巨型植物、枝叶生物、种子航线、山脊守护者、会移动的花园结构。
- 城市 / 街道：由窗格、路牌、栏杆或灯带演化的城市伙伴、悬空交通、折叠建筑或夜行光路。
- 室内 / 咖啡馆 / 美食：从杯沿、蒸汽、餐盘、桌面和食材形状发展出的微型世界、食物角色或室内气象。
- 湖面 / 河流：倒影生物、漂浮花园、水纹道路、航行伙伴或由桥梁延伸的幻想结构。

每次必须选择最贴合当前照片、又不遮挡地点识别度的方案。连续处理多张照片时主动更换原型与中型元素组合。

## 首轮生成前自检

只有全部回答“是”才允许调用图像工具：

- 真人是否明确由原照片像素保留，而不是“生成得像本人”？
- 主奇观是否不是默认鲸鱼或其他案例复刻？
- 主奇观是否至少两项同源于当前场景？
- 是否有一条可描述的视线路径把奇观连回真人？
- 是否写清三个真实遮挡、承托或穿插关系？
- 中型元素是否各有功能，而非装饰清单？
- 是否存在高、中、低三档细节密度？
- 是否只有一个主光事件，且服从原照片？
- 是否规定了四层二维光色与边缘软硬？
- 是否明确排除人物重绘、贴纸感、TV 卡通和 3D CG？

若首轮结果只缺局部精度，使用独立幻想层或局部遮罩修正；不要整图重抽。
